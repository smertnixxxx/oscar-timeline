# Оскар — стрічка часу

Односторінковий сайт: інфографіка про статуетку «Оскар», рекорди кінопремії та хронологічна стрічка з 24 ключових подій (1929–2025).

Зібрано на основі шкільної інфографіки (джерело: New Voice) та додаткових джерел.

## Що є на сторінці

- **Hero** — статуетка (власний SVG) і приглушене архівне фото
- **Статуетка** — факти з інфографіки: габарити, автори, матеріали, 5 спиць
- **Рекорди** — найуспішніші фільми, фільми з усіма 5 головними нагородами, касові рекорди
- **Галерея** — 8 історичних фото з Wikimedia Commons
- **Хронологія** — 24 події з фільтром за епохами
- **Тур по роках** — покрокове читання подій із жартами
- **Лайтбокс** — клік по фото відкриває його на весь екран
- **Джерела** — поправки до інфографіки

## Структура

```
index.html    розмітка
styles.css    стилі, анімації, адаптив, стилі друку
script.js     дані подій, фільтр, тур, лайтбокс, анімації
img/          8 фото (Wikimedia Commons)
_serve.js     локальний статичний сервер (не входить у репозиторій)
```

## Локальний запуск

Просто відкрити `index.html` подвійним кліком.

Або через сервер:

```bash
node _serve.js 8787
# http://localhost:8787/
```

## Технології

Чистий HTML, CSS і JavaScript. Без збірки, без залежностей, без фреймворків.

## Застереження щодо точності

Частина дат і цифр узята з інфографіки й не звірена з офіційною базою AMPAS. Два місця відомо неточні:

- Категорії «другого плану» запроваджені для фільмів **1936 року** (перші нагороди — 1937), а не 1939, як на інфографіці.
- Фото `ceremony-1929.jpg` має власний підпис **«Second Anniversary … MAY 16, 1930»**, тому рік у підписі не заявлений.

Для академічної роботи звіряйте з [oscars.org](https://www.oscars.org).
